# Getting help

## Questions and ideas

Ask in [GitHub Discussions](https://github.com/bursar-world/bursar/discussions). It is the right
place for how-to questions, integration help, and ideas that are not yet a concrete feature
request. Search first; someone may have asked already.

Include what you are trying to do, the commit or package you are using, and the full error
message. Leave out keys, passwords and API tokens.

## Bugs and feature requests

Open an [issue](https://github.com/bursar-world/bursar/issues/new/choose) using one of the
templates.

## Announcements

Release notes and service announcements are posted on X at
[@UseBursar](https://x.com/UseBursar) and in [CHANGELOG.md](CHANGELOG.md). Product information is
at [bursar.world](https://bursar.world).

## Security vulnerabilities

Do not report vulnerabilities in Discussions, issues, pull requests or on X. Follow
[SECURITY.md](SECURITY.md) and email hello@bursar.world or use GitHub private vulnerability
reporting.

## Response times

Discussions and issues are answered by maintainers and other contributors as time allows. There
is no paid support and no guaranteed response time outside the security process.
